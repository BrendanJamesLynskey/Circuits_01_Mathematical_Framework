# Circuits 01 — A Mathematical Framework for Transformer Circuits

**A Mathematical Framework for Transformer Circuits** (Elhage, Nanda, Olsson et al., Anthropic, 22 December 2021) is the founding paper of the Transformer Circuits Thread and the source of the vocabulary the whole field now uses. Its core move is to re-describe a transformer as readable mathematics: a shared **residual stream** that every component reads from and writes to, with attention heads acting as **independent, additive** operations. Each head factors into two near-independent circuits — the **QK circuit** (`W_Q`ᵀ`W_K`, which decides *where* it attends) and the **OV circuit** (`W_O W_V`, which decides *what* it writes). **Freezing the attention patterns** makes the rest of the computation linear, so the model decomposes into a sum of interpretable matrix-product **paths** (path expansion / **virtual weights**). The paper then climbs by depth: zero-layer models are **bigram** tables read straight from `W_E·W_U`; one-layer models are bigram + **skip-trigram** ensembles (with the "skip-trigram bug"); and two-layer models use head **composition** (Q/K/V) to build **induction heads** — prefix-matching plus copying, a genuine in-context-learning algorithm. The analysis is honestly scoped to **attention-only** models; MLPs remain an open problem. For an engineer, this paper is the dictionary behind every later interpretability result and a sturdier mental model of why in-context learning works.
